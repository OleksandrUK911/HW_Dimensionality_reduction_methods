# Пониження розмірності для аналізу портретів клієнтів

## 📋 Опис проєкту

Цей проєкт присвячений застосуванню методів пониження розмірності для аналізу та візуалізації сегментації клієнтів на основі їх поведінкових характеристик та демографічних даних. В рамках роботи проводиться детальний аналіз ефективності методів **PCA (Principal Component Analysis)** та **t-SNE (t-Distributed Stochastic Neighbor Embedding)** для візуалізації результатів кластеризації.

### 🎯 Мета роботи

Customer Personality Analysis - це аналіз різних сегментів клієнтів компанії, який дозволяє:
- Краще розуміти потреби та поведінку клієнтів
- Адаптувати продукти під конкретні сегменти аудиторії
- Оптимізувати маркетингові кампанії та зосередити зусилля на цільових сегментах
- Підвищити ефективність бізнес-стратегій

## 📝 Структура роботи

### Завдання 1: Кластеризація та PCA візуалізація (3D)

**Мета:** Провести кластеризацію клієнтів та візуалізувати результати у 3D просторі головних компонент.

**Кроки:**
1. Відбір ключових характеристик для аналізу:
   - Income (дохід)
   - Recency (давність останньої покупки)
   - NumStorePurchases (покупки у магазинах)
   - NumDealsPurchases (покупки зі знижками)
   - days_lifetime (тривалість співпраці)
   - years_customer (вік клієнта)
   - NumWebVisitsMonth (відвідування сайту)

2. Стандартизація даних за допомогою `StandardScaler`
   - Вирівнювання дисперсії ознак
   - Забезпечення рівномірного впливу всіх характеристик

3. Кластеризація методом `K-Means` (3 кластери)
   - Виявлення природних групувань клієнтів
   - Аналіз розподілу клієнтів по кластерам

4. Пониження розмірності методом `PCA` до 3 компонент
   - Зменшення розмірності з 7 до 3 вимірів
   - Збереження максимальної варіації даних

5. 3D-візуалізація результатів
   - Інтерактивний графік з Plotly
   - Аналіз чіткості розділення кластерів

**Результат:** Успішна візуалізація 3 кластерів клієнтів у просторі головних компонент.

---

### Завдання 2: Аналіз поясненої дисперсії

**Мета:** Оцінити, наскільки добре головні компоненти зберігають інформацію з оригінальних даних.

**Аналіз:**
- Розрахунок частки поясненої дисперсії для кожної компоненти (`explained_variance_ratio_`)
- Обчислення кумулятивної дисперсії
- Візуалізація індивідуального та кумулятивного внеску компонент

**Інтерпретація:**
- PC1 пояснює найбільшу частку варіації
- PC2 та PC3 додатково виявляють інші важливі аспекти
- Три компоненти разом зберігають значну частку інформації (>70%)

---

### Завдання 3: Інтерпретація Loadings

**Мета:** Зрозуміти, які оригінальні ознаки найбільше впливають на кожну головну компоненту.

**Поняття Loadings:**
- **Loadings (навантаження)** - коефіцієнти, що показують внесок кожної вихідної ознаки у головні компоненти
- Доступні через атрибут `pca.components_`
- Високе абсолютне значення = сильний вплив ознаки на компоненту

**Аналіз:**
- Створення DataFrame з loadings для всіх компонент
- Визначення топ-3 найвпливовіших ознак для кожної компоненти
- Візуалізація навантажень (bar charts та heatmap)
- Інтерпретація позитивних та негативних впливів

**Результат:** Виявлення ключових ознак, що визначають кожну головну компоненту.

---

### Завдання 4: Аналіз впливу ознаки Income

**Мета:** Дослідити, як зміняться результати PCA після видалення важливої ознаки.

**Експеримент:**
1. Видалення ознаки `Income` з набору даних
2. Повторне виконання PCA на редукованому наборі
3. Порівняння loadings: до та після видалення
4. Аналіз зміни поясненої дисперсії

**Висновки:**
- Income є критично важливою ознакою для сегментації
- Видалення Income змінює структуру головних компонент
- Інші ознаки не можуть повністю компенсувати втрату інформації
- Пояснена дисперсія зменшується після видалення Income

**Практичне значення:** Демонстрація важливості ретельного відбору ознак.

---

### Завдання 5: Візуалізація з t-SNE

**Мета:** Порівняти результати візуалізації PCA та t-SNE, виявити переваги кожного методу.

**t-SNE характеристики:**
- Нелінійний метод пониження розмірності
- Зберігає локальні структури та відстані між близькими точками
- Ефективний для візуалізації складних структур даних

**Виконані кроки:**
1. Застосування t-SNE для зниження розмірності до 2D
2. Створення інтерактивних візуалізацій з hover-даними
3. Додаткові візуалізації з варіюванням розміру точок (Income, NumStorePurchases)
4. Аналіз характеристик кластерів через середні значення ознак
5. Порівняння візуалізацій PCA 2D та t-SNE

**Ключові відмінності:**

| Характеристика | PCA | t-SNE |
|---------------|-----|-------|
| Збереження структури | Глобальна | Локальна |
| Інтерпретація компонент | Через loadings | Візуальна |
| Розділення кластерів | Менш виражене | Більш чітке |
| Відстані між кластерами | Інтерпретовані | Не інтерпретовані |
| Швидкість | Швидко | Повільніше |
| Застосування | Аналіз та моделювання | Візуалізація |

### Попередня обробка даних

1. **Обробка пропущених значень:**
   - Заповнення відсутніх значень Income значенням -1
   - Створення індикаторної змінної `Income_not_filled`

2. **Обробка дат:**
   - Конвертація `Dt_Customer` у datetime формат
   - Обчислення `days_lifetime` - тривалості співпраці
   - Обчислення `years_customer` - віку клієнта

3. **Категоріальні змінні:**
   - One-hot encoding для рівня освіти
   - Очищення та кодування сімейного стану

4. **Очищення викидів:**
   - Видалення аномальних значень Income (666666)

5. **Стандартизація:**
   - Застосування `StandardScaler` перед PCA та кластеризацією
   - Забезпечення рівномірного впливу ознак

### Кластеризація

- **Алгоритм:** K-Means
- **Кількість кластерів:** 3
- **Параметри:** random_state=42, n_init=10
- **Метрика:** Евклідова відстань на стандартизованих даних

### Пониження розмірності

**PCA:**
- Кількість компонент: 3 (для 3D) та 2 (для порівняння)
- Метод: Singular Value Decomposition (SVD)
- Масштабування: StandardScaler

**t-SNE:**
- Кількість компонент: 2
- Perplexity: 30
- Max iterations: 1000
- Random state: 42
